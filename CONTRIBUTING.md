# Contributing

Report game build, REFramework version, chapter, difficulty, map floor, destination and whether other mods were enabled. Describe whether the map closed, whether the player moved and whether F7 worked. Redact private file paths and do not upload save files or full logs by default.

Keep ground validation and bounded waits. Avoid changes to save data or chapter flags in this project's teleport flow. Document which paths were actually tested. Changes to region selection should include a reproducible destination and a confirmed return path.
